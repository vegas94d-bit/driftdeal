# driftdeal

Браузерная 2D-игра про дрифт с видом сверху. Вся игра находится в одном файле `index.html`: чистые HTML, CSS и JavaScript, графика рисуется через Canvas, внешних картинок, звуков и библиотек нет.

## Запуск

Открыть `index.html` в браузере. Сборка и сервер не нужны.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W` / `↑` | газ |
| `S` / `↓` | тормоз / задний ход |
| `A` `D` / `←` `→` | руль |
| `Пробел` | ручной тормоз (занос) |
| `R` | рестарт |

## Геймплей

- Замкнутая асфальтовая трасса с поребриками, гравийной зоной вылета и стенами.
- Очки заноса начисляются на трассе при скорости и угле скольжения выше порога.
- Множитель растёт за непрерывный дрифт: `x2` через 2 с, `x3` через 4 с, `x5` через 7 с.
- Очки заноса попадают в общий счёт только после завершения дрифта; вылет с трассы или удар о стену сжигают их.
- Рекорд сохраняется в `localStorage`.
